# AI Summary Template (JJ_Vault)

Use this template to write `ai_summary.md` from the human notes + SRT.
Focus on context that is missing or unclear in the notes.

## Template

```markdown
## AI 보완 내용 (SRT 기반)

### 운영 원칙/툴링 보완
- 

### 자료 구조/보안 기준 보완
- 

### 계정/저장소 운영 디테일
- 

### 편성/제작 사이클 디테일
- 

### 개인/팀 계획 보완
- 

### 프로젝트/사업/아이디어
- 

### 확인 필요
- 
```

## Guidance

- Keep the content concise and additive (do not restate the notes).
- Prefer action items, decisions, constraints, metrics, and schedules.
- If SRT conflicts with notes, flag it under "확인 필요".
